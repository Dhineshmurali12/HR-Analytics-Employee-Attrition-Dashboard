# 📊 HR Analytics & Employee Attrition Dashboard

An end-to-end Data Analytics project built using **Python, SQL, and Power BI** to analyze employee attrition, workforce demographics, performance, satisfaction, and HR KPIs.

---

## 🚀 Project Overview

This project demonstrates the complete analytics workflow:

- Data Cleaning using Python
- Exploratory Data Analysis (EDA)
- SQL Business Analysis
- Data Modeling
- Power BI Dashboard Development
- HR KPI Tracking
- Interactive Dashboards
- Business Insights
